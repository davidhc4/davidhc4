Preguntas frecuentes

¿Mis datos se suben a algún lado?

No. La herramienta gratuita funciona por completo en tu navegador. Puedes desconectar el internet después de abrir la página y sigue funcionando.

¿Qué formato debe tener el archivo?

CSV o Excel con una fila por lote. Las columnas se detectan por nombre: producto/nombre/descripción, lote, vencimiento/vence/fecha, cantidad/existencia/stock, costo/precio. Las fechas pueden venir como 31/12/2026, 2026-12-31 o 12/2026.

¿Con qué sistemas funciona el plan automático?

Con cualquiera que guarde los datos en SQL Server, MySQL, PostgreSQL o archivos exportables. Primero reviso tu sistema sin costo y te digo si se puede conectar.
