# Hola, soy David

Vivo en Colombia y programo para resolver problemas reales: automatizar tareas repetitivas, trabajar con bases de datos y hacer aplicaciones para el celular. Vengo del mundo de las farmacias y la distribución de medicamentos, y de ahí me quedó el gusto por los procesos que ahorran tiempo.

Sigo aprendiendo. Estudio Python y SQL con más constancia cada semana, y redes y servidores por mi cuenta.

## En qué trabajo

- **Automatización con Python**: scripts que manejan páginas web (Playwright), programas de escritorio (pywinauto) y bases de datos SQL Server (pyodbc).
- **SQL Server**: consultas e informes de ventas, márgenes e inventario sobre el sistema de una farmacia.
- **Apps para Android**: las desarrollo y las publico yo mismo.

## Proyectos

### [Bolsillo](https://github.com/davidhc4/app-contabilidad)
App de control de gastos personal para Android, hecha con Flutter. Gratis, de código abierto, sin anuncios, sin cuentas y sin permiso de internet: los datos se quedan en el teléfono. Tiene presupuesto mensual, tarjetas y cuentas, transferencias, estadísticas y copia de seguridad en CSV. Se instala desde la sección Releases.

### [Música](https://github.com/davidhc4/app-musica)
Reproductor de música para Android en Kotlin, con Jetpack Compose y Media3. Está pensado para funcionar sin conexión y sin anuncios. Los componentes se hablan por medio de un mediador central, así que si uno falla no tumba a los demás. Todavía está en construcción.
